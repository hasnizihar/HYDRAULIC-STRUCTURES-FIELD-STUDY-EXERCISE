Structure: Downstream Left Branch Delivery Canal (Vammiyadiyuttu Alignment)

1. FORMULATION & GOVERNING EQUATIONS
Trapezoidal Channel Geometry:
  - Cross-sectional Area: A = y * (b + z * y)
  - Wetted Perimeter: P = b + 2 * y * sqrt(1 + z^2)
  - Hydraulic Radius: R = A / P
  - Top Width: T = b + 2 * z * y
  - Hydraulic Depth: D = A / T
  - Conveyance Capacity (Manning): Q = (1 / n) * A * R^(2/3) * S_0^(1/2)
  - Mean Flow Velocity: V = Q / A
  - Froude Number: Fr = V / sqrt(g * D)
  - Available Safety Freeboard: F_b = H_bank - y

--------------------------------------------------------------------------------
2. BASE-CASE CALCULATION
Inputs:
  - Bottom width: b = 3.00 m (Photo-estimated)
  - Side slope: z = 1.25 (1.25H:1V, Photo-estimated / ID standard)
  - Total bank height: H_bank = 1.70 m (Photo-estimated)
  - Representative flow depth: y = 1.10 m (Analytical full-supply depth)
  - Manning roughness: n = 0.030 (Ven Te Chow Table 5-6: Earth bed, grassed banks)
  - Longitudinal bed slope: S_0 = 0.0008 (1 in 1,250, Engineering analysis assumption)

Step-by-Step Values:
  - A = 1.10 * [3.00 + 1.25(1.10)] = 4.8125 m^2
  - P = 3.00 + 2(1.10)*sqrt(1 + 1.25^2) = 6.5217 m
  - R = 4.8125 / 6.5217 = 0.7379 m
  - R^(2/3) = (0.7379)^0.6667 = 0.8164 m^(2/3)
  - S_0^(1/2) = sqrt(0.0008) = 0.028284
  - Q = (1 / 0.030) * 4.8125 * 0.8164 * 0.028284 = 3.7051 m^3/s ≈ 3.71 m^3/s
  - V = 3.7051 / 4.8125 = 0.7699 m/s ≈ 0.77 m/s
  - T = 3.00 + 2(1.25)(1.10) = 5.750 m
  - D = 4.8125 / 5.750 = 0.8370 m
  - Fr = 0.770 / sqrt(9.81 * 0.8370) = 0.269 (Tranquil Subcritical Flow)
  - Freeboard F_b = 1.70 - 1.10 = 0.60 m
